# Durable Knowledge

Stable project, architecture, domain, ownership, and decision context belongs here.

## Inventory

| File | Purpose |
| --- | --- |
| `project-overview.md` | Project purpose, boundaries, architecture, commands, and source map. |
| `agent-collaboration.md` | Practical guidance for efficient and reliable agent work. |
| `engineering-principles.md` | Default implementation and review principles. |

## Rules

- Prefer updating an existing note over creating a competing source.
- Keep each note focused and link to authoritative sources.
- Include metadata from `../templates/durable-note.md`.
- Reverify material claims when their `Review When` condition applies.
- Do not store task chronology, raw logs, credentials, or transient runtime state here.
