# Templates

Reusable document shapes live here.

| Template | Use |
| --- | --- |
| `task.md` | Current task state and continuation handoff. |
| `durable-note.md` | Source-backed project or domain knowledge. |
| `runbook.md` | Repeatable procedure with boundaries and validation. |
| `system-landscape.md` | Repositories, services, environments, delivery, data, observability, and capability map. |

Templates define structure only. Live content belongs in `tasks/`, `knowledge/`, or `runbooks/`.
